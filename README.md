## 📚 Week 1: Excel & Data Cleaning

**Focus:** Mastering Excel fundamentals and data cleaning techniques

### Deliverables
- ✅ Data deduplication and missing value handling
- ✅ Pivot table analysis (region-wise sales)
- ✅ Statistical calculations using Excel formulas (Mean, Median, Mode)
- ✅ Conditional formatting (Top 10 Sales highlighting)
- ✅ Data visualization with charts
- ✅ Comprehensive dashboard with KPIs

### Key Skills Developed

- Data cleaning workflows

- Chart and dashboard design
